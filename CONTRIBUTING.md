# Contributing to Consumer Spending Power

Thank you for considering a contribution. This is a Tableau analytics project, so contributions are about the analysis and the dashboard.

## Ways to contribute

- **Improve the analysis.** If a figure or a calculation looks wrong, open an issue with the page name and the proposed change.
- **Add a view.** A new chart that answers a real business question is welcome. Fork the repository, add the sheet, and send a pull request with a screenshot.
- **Sharpen the documentation.** If a sentence in the README is unclear or wrong, open an issue or a pull request with the rewrite.
- **Port to another tool.** Power BI or Excel versions are welcome in their own folder.

## How to submit

1. Fork the repository
2. Create a branch named for your change
3. Make the change in a copy of the workbook so the original is preserved
4. Update the README if the change affects the findings
5. Open a pull request that says what changed and why

## Questions

Open an issue with the `question` label.
